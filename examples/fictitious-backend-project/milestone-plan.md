# Planejamento da Milestone: v1.0.0 - MVP

## Objetivo
Entregar uma API REST funcional que permita criar, listar, editar e excluir tarefas. O MVP deve ser suficiente para validar a arquitetura e receber feedback inicial.

## Prazo
4 semanas a partir do inicio do desenvolvimento.

## Criterios de Conclusao
- Todas as Issues vinculadas a esta Milestone estao fechadas.
- A API responde corretamente aos endpoints de CRUD.
- O deploy em ambiente de homologacao esta funcional.
- A documentacao basica da API (README do projeto) esta atualizada.
