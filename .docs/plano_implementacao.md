# Plano de Implementação: GitHub Project Playbook

Este documento orientará as etapas de desenvolvimento do MVP, servindo de base para o acompanhamento e organização.

## Objetivo
Criar a fundação do repositório educacional `Github-Project`, que ensinará gestão de projetos usando ferramentas nativas do GitHub.

## Fase 1: Fundação do MVP (Atual)
- [x] Inicialização do repositório Git.
- [x] Criação da estrutura de pastas base (`docs`, `.docs`).
- [x] Criação do `README.md`.
- [x] Criação do `docs/00-scope-and-principles.md`.
- [x] Criação do `CONTRIBUTING.md`.
- [x] Criação do `.gitignore`.
- [x] Criação da `LICENSE`.

## Fase 2: Configuração e GitHub Projects (Próximos passos)
- Configurar manualmente a primeira Milestone (MVP).
- Criar as primeiras Issues para o projeto.
- Configurar o Kanban (GitHub Projects).

*Nota: Nenhum script de automação será criado nesta fase, garantindo um aprendizado passo a passo.*
